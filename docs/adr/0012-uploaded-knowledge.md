# ADR 0012: アップロード資料のチャット別利用設定と共同編集

- 日付: 2026-11-01
- 状態: 採用

## 決定

- `knowledge_documents` に所有者・タイトル・原本名・本文・版・更新者を保持し、`knowledge_document_chats` にチャット別の有効状態と検索用メッセージIDを持つ。原本は非公開 R2 に一つ保存する。
- 本人と bot が現在参加中のチャットをチェックして共有する。本人は自分の新しい参加チャットへ共有を追加できる。他の参加者は既に関連付いたチャットの有効・無効だけを変更でき、新しいチャットへ他人の資料を共有追加できない。
- 原本削除は所有者限定。全文の閲覧と編集は、所有者または関連チャットの現在の参加者に許可する。利用の無効化は AI の参照設定であり、チャット参加者の全文閲覧・編集権を取り消すものではない。
- ファイルまたは本文の貼り付けを受け付ける。原本10MB、画像4MB、PDF10ページ、抽出本文40,000文字まで。上限を超える本文は全文として一部だけ保存せず、分割登録を案内する。解析には既存の安価なモデルと予算を使う。
- 一つの canonical メッセージで解析・埋め込みし、チャット別の検索用メッセージには本文とベクトルをコピーする。Vectorize の namespace は従来どおりチャットIDにし、全文は D1 に保存する。複数チャットへ共有しても AI 解析を繰り返さない。
- `available_messages` ビューで、有効なチャット・未削除の資料・現在の版・索引化済みのメッセージだけを返す。検索、bot の根拠確認、1対1の過去対話の再利用で同じビューを使い、Vectorize の削除完了に依存しない。
- 無効化はそのチャットだけに適用し、他チャットは維持する。関連資料を根拠にした保存済み bot 回答も無効化する。原本削除と削除待ち状態の記録を同じ D1 トランザクションにし、キュー送信に失敗しても Cron が後から削除する。
- 全文リンクは `/knowledge/<id>?conversationId=<トークID>`。LINE ログイン後に同じページへ戻る。本文は HTML として描画せず、テキスト欄で閲覧・編集する。原本ダウンロードも認証・現在の参加確認を必須とする。
- 編集は表示した revision に対する条件付き UPDATE と編集トークンで直列化する。競合は409とし、後続の書き込みも同じトークンに一致した場合だけ実行する。新しい canonical / チャット別メッセージIDを作り、旧版を即時に参照対象から外す。処理中の旧版が後から公開されても現在の版として見えない。
- 共同編集は全共有先へ反映する。編集対象は抽出本文とし、アップロード原本は変更しない。検索結果に全文URLと資料名を付け、LINE の回答にも認証付き全文リンクを添える。登録日時と出来事の日時を混同しない。
- API の変更は既存のセッション・同一 Origin・CSRF の検証を利用する。操作ごとに現在の参加を確認する。管理画面の一覧は最新100件、共有先の初期選択は20件まで。

## 検証

複数チャットでの埋め込み再利用、他人の資料の切り替えと削除拒否、関係ないチャットへの共有拒否、無効化・編集と検索索引の競合、全文URL、閲覧・編集の参加確認、同時編集の競合、旧版の非表示、原本の削除キュー失敗時の再試行をテストする。
