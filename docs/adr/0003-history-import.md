# ADR 0003: 過去ログは書き出しを優先して取り込む

- 日付: 2026-11-01
- 状態: 採用・実装予定

## 背景

Messaging API は、bot 参加前の履歴を一括取得する手段を提供しない。ユーザーは既存の会話もナレッジに取り込みたい。

## 決定

- LINE アプリのテキスト書き出しを優先し、Computer Use で書き出し操作を支援する。
- 書き出しで不足する場合、アプリで閲覧できる範囲をスクロール・コピーなどで補完する。
- 取得元、取得方法、対象期間、元データ位置、重複候補を保持し、全履歴取得を保証しない。
- 表示名と Webhook のユーザーID、書き出し発言と Webhook 発言は根拠なく同一と断定しない。
- 原本やインポート用ファイルは Git に含めない。

## 結果

画面を大量に読み取る時間とトークン消費を抑えられる。端末にない履歴は取得できない。
インポーター、日付・改行の解析、重複照合、人物対応表は後続で実装する。
