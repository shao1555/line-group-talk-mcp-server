# ADR 0002: ナレッジ整理を明示起動する

- 日付: 2026-11-01
- 状態: 採用・実装予定

## 背景

全発言を常時 LLM に渡して要約すると、不要なトークン消費が発生する。

## 決定

- 通常運転では会話の記録と検索を行い、常時の LLM 要約は行わない。
- ユーザーが Codex などでスキルを明示起動したときに、会話から決定事項・タスク・話題を抽出する。
- スキルは MCP 経由で未処理範囲を取得し、元発言IDを付けて整理結果を保存する。
- 提案・推測と確定した決定事項を区別する。
- 処理量の上限、処理済み位置、途中再開、再実行時の重複防止を設ける。
- 埋め込み生成と索引更新は要約とは別の処理として扱う。未整理の会話も検索できる構成を目指す。

## 結果

サーバーで要約用 LLM を常時呼ぶ必要はない。スキル実行時の AI 利用枠と埋め込み処理の費用は必要。
整理済みナレッジには更新の遅れがあるため、処理した範囲と日時を表示できるようにする。
スキル、MCP の書き込みツール、会話の分割単位、埋め込み更新タイミングは後続で実装する。
