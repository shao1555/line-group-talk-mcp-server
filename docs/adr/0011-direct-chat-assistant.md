# ADR 0011: 1対1のナレッジアシスタントとユーザー別24時間予算

- 日付: 2026-11-01
- 状態: 採用

## 決定

- `source.type = user` の署名済み LINE Webhook からユーザーIDを識別する。テキストにはメンションなしで回答し、`ping` は既存の pong を維持する。グループ内の検索範囲は変更しない。
- Workers AI `@cf/qwen/qwen3-30b-a3b-fp8` を1対1の回答専用に採用する。モデルの総パラメータ規模は30B、コンテキストは32,768トークン。入力 $0.0509 / 出力 $0.335 per million tokens（2026-11-01確認）。画像解析やグループの短い回答のモデルは変更しない。
- MCP と同じ参加確認・検索・履歴読み取りをアプリ内で利用する。モデルが JSON の読み取り操作を選び、一覧・直近メッセージ・意味検索を実行する。モデルが指定したトークIDを信頼せず、現在の参加を確認したトークの許可リストと照合する。読み取りだけを許可し、最大3推論・4ツール操作に制限する。
- 送信日時を基準に時期を解釈し、発言日時と出来事の時期を区別する。直近の質問は履歴、過去の出来事は必要な範囲の意味検索を使う。bot の発言も役割付きで読める。bot の提案を人間の決定と見なさず、記録と一般知識を分ける。Web 検索は行わない。
- 毎回、現在参加を確認したトークの直近6件ずつを読み直す（最大5トーク・全体8KBで均等配分）。過去の1対1の話題や「記録がない」という bot 回答だけで新しい質問の範囲を固定しない。直近で不足する場合はモデルが関連トーク・意味検索を選ぶ。トーク名・発言日時付きの資料として渡し、正月と1/1などの表現の違いを結び付ける。
- 1対1の直近対話は D1 から取得する。過去の bot 回答の根拠へのアクセスと取消状態を確認し、退会後の元トークの内容を対話履歴から再提示しない。送信直前にも全根拠の参加権限と取消状態を確認する。グループ由来の回答は1対1トークにだけ送る。
- 1対1の本文・回答は背景の索引化から除外する。検索用の埋め込みと回答生成だけを同期のユーザー別課金対象にする。画像・音声等の直接入力に対するアシスタント応答は後続対象。

- 1対1の送信には quoteToken を付けず、通常のメッセージとして返す。過去対話の文脈は保持する。グループの引用返信は維持する。
- リクエストID・候補トーク数・読み取った件数・選択したツールと件数を構造化ログに残す。本文・検索語・認証情報はログに出さない。

## ユーザー別利用料金

- `ai_usage.owner_user_id` に Webhook から得た本人IDを付け、`created_at > now - 24 hours` の `charged_microusd` を集計する。呼び出し元から渡された ID やセッションの共通状態を使わない。
- ユーザー別上限は24時間で $0.50（500,000 micro-USD）。D1 の単一条件付き INSERT により、全体の月額・日次制限とユーザー上限を同時に確認して予約する。並行リクエストでも予約額の合計を上限以内にする。
- 1推論は最大1024出力トークン・入力のバイト上限を設け、$0.0025 を予約する。正常な使用トークン数が返れば公開単価による実績相当額に更新する。失敗・使用量不明では予約を維持する。検索用埋め込みも同じユーザーIDで記録する。
- 残額が保守的な予約額を下回る場合も呼び出しを控える。上限到達・予約不能の通常の質問には返信せず `blocked` と記録する。未処理の質問を後から自動送信しない。
- $0.40 以上では返信末尾に「直近24時間の利用量の80%に達しました」と上限を添える。生成失敗後の固定文や再送時にも適用する。上限を確認するために追加モデルを呼ばない。
- 「利用状況は」「利用率は」「いまどのくらい使った？」「利用状況を教えて」「残り予算」「usage」等を定型処理し、AI を使わず直近24時間の料金・残額を返す。ユーザー別・アプリ全体の上限に達した後も利用できる。
- 実請求額を取得する機能ではなく、公開単価による見積り・予約額の管理。インフラ料金を含めない。24時間を過ぎた利用分から順に回復する。

## 検証

メンション不要、モデル指定、送信済み記録、許可トークのみの検索、bot 役割、検索埋め込みの課金先、退会後の対話・送信前の権限再確認、ユーザー間の料金分離、並行予約、$0.40警告・$0.50無応答・無料の利用状況、24時間経過と失敗時予約をテストする。
